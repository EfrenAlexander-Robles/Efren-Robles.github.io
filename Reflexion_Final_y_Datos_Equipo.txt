2. DESCRIPCIÓN DEL SITIO Y RESPONSABILIDADES
--------------------------------------------
El sitio web promocional "Huellitas al Mictlán 2026" fue diseñado para informar e involucrar a la comunidad escolar del CBTis 246 en la celebración del Día de Muertos. 
Organización de responsabilidades:

3. REFLEXIÓN FINAL
------------------
¿Qué aprendieron durante el desarrollo de esta página web?
Aprendimos a integrar tecnologías web modernas (HTML5 semántico, CSS3 responsivo y JavaScript manipulando el DOM) orientadas a un propósito cultural específico. Desarrollamos habilidades para manejar animaciones en Canvas y el uso de la Web Audio API para generar ambientes sonoros.

¿Cuál fue la parte más complicada y cómo la resolvieron?
La parte más complicada fue coordinar la interactividad del altar virtual junto con la animación fluida de los pétalos de cempasúchil sin afectar el rendimiento en dispositivos móviles. Lo resolvimos estructurando código modular con eventos optimizados y consultas de medios CSS (Media Queries).

¿De qué manera la tecnología puede ayudar a preservar y difundir nuestras tradiciones mexicanas?
La tecnología permite reinterpretar las tradiciones para las nuevas generaciones, creando espacios digitales accesibles e interactivos que trascienden barreras físicas, permitiendo rendir tributo y difundir la riqueza de nuestras raíces culturales de forma creativa.
